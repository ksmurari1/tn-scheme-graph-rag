# Applying the updated SmartAgri AI documentation

1. Back up the current `README.md` and `docs/` folder.
2. Copy the updated `README.md` into the repository root.
3. Copy the updated Markdown files from `docs/` into the existing `docs/` folder.
4. Keep your existing screenshots in the repository's `images/` folder and rename them to:
   - `images/query-graph.png`
   - `images/schema-graph.png`
5. Review the setup commands and check that script names match the files in your local repository before publishing.
6. Do not add `.env`, credentials, logs, or virtual-environment files to Git.

The documentation describes the current implementation based on the supplied project context. Please validate paths and script names in your working tree before committing.
